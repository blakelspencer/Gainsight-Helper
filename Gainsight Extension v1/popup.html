Gainsight Helper

About:

  • Export Rules: Select which fields to include in output csv, will return first 200 rules currently.
  • Get Layout: Must be on a C360 page, will return name, description of C360 Layout and provide link to edit.
  • Evaluate SFDC Dependencies: Will return total number of SFDC object Gainsight has access to, will download a list of all fields/objects that have dependencies within Gainsight.
  • Get All Dropdowns: should return first 200 dropdowns and all values with GSIDs included as csv.
  • This is very much a work in progress, the code is incredibly messy, hoping to make improvements quickly. Please feel free to message me with feature requests.
